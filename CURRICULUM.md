# Curriculum Guide

This document defines the expected structure for `ai-infra-performance-solutions`.

## Repository Type
- Track type: solutions
- Paired learning repo: `ai-infra-performance-learning`
- Primary content directories: `modules/` + `projects/`

## Top-Level Layout
- `modules/`: per-module reference solutions
- `projects/`: capstone solutions
- `guides/`, `resources/`: cross-cutting material

## Module Minimums
Each module solution directory has 5 exercise subdirectories, each with a
README linking back to the learning exercise + reference code or pointer to
the deeper engineer-solutions implementation.
