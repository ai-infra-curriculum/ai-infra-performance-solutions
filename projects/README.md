# Projects

Project-grade reference solutions for the AI Infrastructure Performance
Engineer track. Each entry pairs with a capstone in the learning repo's
[`projects/`](https://github.com/ai-infra-curriculum/ai-infra-performance-learning/tree/main/projects)
and explains the *why* behind the implementation rather than restating
the spec. Use the learning repo's `requirements.md`, `architecture.md`,
`STEP_BY_STEP.md`, and `rubric.md` as the canonical contract; the
`SOLUTION.md` files here are the reviewer's companion.
